# Neural SDE Framework

> [!NOTE]

## Getting Started

1. **Install Dependencies**:

   ```bash
   uv sync
   ```

## Examples

2. **Run Duffing oscillator**:

   To edit/live-run:

   ```bash
   uv run examples/duffing_oscillator_notebook.py
   ```

3. **Run Nanorings digital twin**:

   ```bash
   uv run examples/nanorings.py
   ```
